Torch Hub là gì?

Torch Hub là plugin tìm kiếm tài liệu trên máy của bạn. Thay vì bắt bạn nhớ chính xác tên file hay nơi lưu, Torch Hub xây một lớp chỉ mục thông minh để hiểu nội dung và trả về đúng thứ bạn cần.

Không di chuyển, không đổi tên, không xáo trộn cấu trúc file gốc của bạn.

Torch Hub là gì?

Torch Hub là plugin giúp tìm lại tài liệu bằng cả tên file lẫn ý nghĩa nội dung, dựa trên một lớp chỉ mục thông minh.

Torch Hub hỗ trợ hệ điều hành nào?

Hiện có bản cho Windows và macOS. Bạn có thể tải ở mục Tải Torch Hub.

Semantic Search khác tìm theo tên như thế nào?

Tìm theo tên yêu cầu bạn nhớ tên file. Semantic Search hiểu ý nghĩa câu truy vấn nên bạn chỉ cần mô tả nội dung tài liệu.

Torch Hub có thay đổi file của tôi không?

Không. Torch Hub xây một lớp chỉ mục phục vụ tìm kiếm và không thay đổi hay di chuyển cấu trúc file gốc.

Khi thêm hoặc sửa file, tôi cần làm gì?

Dùng chức năng Update Index để cập nhật danh sách chỉ mục, dữ liệu mới sẽ có thể được tìm kiếm.

Torch Hub có kết nối Google Drive, OneDrive không?

Chưa ở phiên bản MVP. Tích hợp cloud đang nằm trong lộ trình phát triển tiếp theo.

Tôi gặp lỗi hoặc có ý kiến góp ý?

Torch Hub đang trong giai đoạn thử nghiệm, mọi phản hồi của bạn giúp nhóm hoàn thiện sản phẩm nhanh hơn.
